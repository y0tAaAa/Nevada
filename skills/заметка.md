## Что сделать

1. Проверь, открыт ли уже Блокнот: инструмент `app`, action `list_windows`.
2. Если окна Блокнота нет — запусти его: `app` / `launch` с `program: "блокнот"`,
   затем снова вызови `list_windows`, чтобы узнать точный заголовок окна.
3. Вставь текст заметки: `app` / `type_text` с реальным заголовком окна из списка
   и текстом заметки. Пользователь подтвердит действие в диалоге.

## Правила

- Заголовок окна НЕ придумывай — бери строго из вывода `list_windows`.
- Текст заметки — то, что попросил пользователь, без своих дополнений.
- Если пользователь отклонил подтверждение — сообщи об этом и не повторяй попытку.
- Если нужно добавить дату, сначала возьми её из `system` / `get_time`.
