## Что сделать

1. Узнай текущие дату и время: инструмент `system`, action `get_time`.
2. Узнай состояние компьютера: инструмент `system`, action `get_info`.
3. Собери короткую сводку в таком виде:

   - Приветствие по времени суток и сегодняшняя дата.
   - Состояние ПК одной строкой: загрузка CPU, занятая память, аптайм.
   - Если аптайм больше 3 дней — мягко предложи перезагрузиться.
   - Если занято больше 85% памяти — посмотри `system` / `list_processes`
     и назови только ТРИ самых тяжёлых процесса одной строкой. Сам их не закрывай.

## Правила

- Никаких выдуманных цифр: все значения только из вывода инструментов.
- Сводка короткая: 4–6 строк. Никаких таблиц, рамок и нумерованных списков.
- НЕ перечисляй все процессы — максимум три, через запятую.
- Не предлагай действий, которые пользователь не просил.
